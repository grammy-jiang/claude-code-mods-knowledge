# P5 Skill-side P1/P2/P3 — 12 frozen cases x 3, seven Agent stacks

Date: 2026-10-17. Research and development only; not a
production Skill or real ChatGPT Chat-mode Plugin acceptance.

## P1 — Reviewed task-specific Evidence Pack

The deterministic selector in src/mods_knowledge/task_evidence.py
selects up to six approved K-Claims and their exact first-party
official URL anchors from the current version-scoped SSOT. It
cannot invent facts, edit model weights or approve unreviewed APIs.
The command mods-knowledge evidence-select returns a bounded private
text file without accessing the Internet.

The compiled Skill mentions optional references/selected-evidence.md.
Only the isolated QA runner creates this short file. The actual
model read is independently measured from the original native trace.

In the final trial set, zero of twelve positives for each of five
local models and Codex no-web actually opened the optional pack.
Codex web opened it in only one of twelve positives. This is a
major limitation: generating correct evidence is not sufficient
if the Agent never reads it.

## P2 — Route and tool-call convergence

Non-Mod TypeScript, Python, MCP and legacy settings hooks are routed
outside the Mods evidence mechanism. The opt-in Pi test extension
still scopes read-only filesystem tools but also terminates six
adjacent identical calls or the 48th call. No valid native tool
result is cached, fabricated or replaced.

## P3 — Buffered answer gate and honest semantic boundaries

Before inference, unreviewed versions and unsupported host surfaces
are refused. After the model returns, the Pi runner checks that the
original answer itself cites the selected approved Claim/URL pairs,
that the model and Skill are attributable, and that the response is
finished, balanced and not a known executable Mod code hazard.

This buffer is demonstrated ONLY in the local Pi test harness.
No equivalent verified gate was added to Codex App Server or
ChatGPT Chat mode. Citation correctness does not independently
prove generated Mod code semantics, tool value or error identity.

## Authentic 252-turn comparison

The same twelve originally frozen P4 prompts are independently
tested three times for each of five local models and two Codex
Sol/medium configurations. The local model cohort contains
180 turns, Codex 72 turns. Every original native event/wire trace
is retained privately on Mac with SHA256 provenance. No fine-tuning,
model setting changes, global Skill installation or online ChatGPT
Plugin publication occurred.

Thirty serial local model test windows stopped the temporary model
and verified the Mac's original user AI service state was unchanged.
All five user AI services were already unloaded at the start of
this run, so they were not restarted. Emergency actual Swap and
macOS memorystatus limits remained, without an artificial 50%
memory-free threshold.

The first Codex isolate pilot accidentally used the older global
Skill; that invalid evidence was retained, excluded and never
replayed in the corrected 72-turn cohort. Codex's later isolated
registration and actual Skill reads were scored separately.

## Acceptance decision

The full sanitized report is published at
docs/reports/2026-10-17-p5-p123-seven-stack-12x3.md and .json.
P1-P3 produced mixed outcomes: better citations for several local
models, Mistral still 0/12, and both Codex citation cohorts worse
than the prior benchmark. The optional evidence pack was barely
consumed. The source is development-only; do not promote the
installed Skills or claim Stable/ChatGPT Chat/native semantic QA
acceptance. Keep P5 Issue #3 open.
