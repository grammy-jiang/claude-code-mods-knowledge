# P3 Deterministic Knowledge Compiler — 2026-10-13 Verification Report

## Scope and deliverables

This implementation compiles a source-bound SSOT subset into a common Agent Skill and platform-specific directory structures for Claude Code, Codex, Pi Agent, and a Portable Agent Plugins 1.0 ChatGPT Plugin. P3 does **not** install or activate any Skill or plugin.

Active build scope is **Claude Code 2.1.296 on CLI**. All 25 approved Claims are referenced (24 reviewed first-party guidance + one narrow actual local test-kit observation). Five candidate API Claims and the H historical sources are excluded from current API guidance; official example references are navigation-only and explicitly non-normative. Other API versions/surfaces are rejected, not silently downgraded.

## Output contract

`uv run mods-knowledge build --api-version 2.1.296 --surface cli` emits a Git-ignored `dist/` tree with:

- One common, compact `SKILL.md` with version checks, source routing and failure rules, plus six engineering-area reference Markdown documents and two source/example navigation references.
- Byte-identical copies for `dist/claude-code/.claude/skills/`, `dist/codex/.agents/skills/`, and `dist/pi/.agents/skills/`.
- `dist/chatgpt/claude-code-mods-knowledge/plugin.json` using root Portable Agent Plugins 1.0 syntax, with a fourth byte-identical Skill, **no MCP servers, hooks, authentication, or executable scripts**.
- Two stable ZIP bundles under `dist/packages/` and content hashes plus input provenance under `dist/manifests/`.

The manifest includes compiler/knowledge/package versions, target API version and host surface, selected Claim IDs, source revision, per-input SHA-256 (including validation code, source schemas, runtime evidence, original source registry and reviewed sections), and SHA-256 of every bundle/output file. No build clock or random identifier is serialized; ZIP timestamps are all normalized to 1980-01-01.

## Security and reproducibility limits

Recorded reviewer labels and hash chains are not cryptographic signatures; the approved guidance means first-party source headings and artifacts were reviewed with declared scope, not that every official API was exercised live. The original HTML bytes were never copied into the repository. Current official Markdown section digests are metadata-only and cannot be recomputed without accessing the exact upstream bytes. A Git HEAD source revision alone cannot prove a dirty working tree contains the same inputs; compare the manifest's full input hash set when releasing.
