## Mandatory fail-closed release sequence

1. Before compiling or releasing, run the online latest gate using
   Python script scripts/check_latest_claude_code.py with flags
   --target-version 2.1.302 --require-installed --require-approved.
   It uses a fixed HTTPS official npm registry endpoint, performs no
   Agent inference and never installs or executes a plugin.
2. Independently review changed documentation and version-specific
   native semantics, recording new auditable source revisions while
   retaining the old Claim applicability and approval history.
3. Approve exact 2.1.302 CLI knowledge. Then build the Claude Code,
   Codex, Pi Agent and ChatGPT Plugin packages from those reviewed
   Claims only; verify hash manifests and native Agent loading.
4. Deploy the updated Plugin and separately verify real **ChatGPT
   Chat Mode** activation. Codex App Server tests and synthetic native
   fixtures cannot substitute for this acceptance.
5. Immediately before production promotion, check the official latest
   tag again. If it changed, stop and repeat the review/build cycle.
