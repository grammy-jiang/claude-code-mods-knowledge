## Target-version smoke evidence

On MacBook Pro, `claude --version` returned `2.1.296 (Claude Code)`. Running `claude plugin validate ./tests/fixtures/mods-cli-smoke` reported `Validation passed` and hooks `session.start`, `tool.call`, `command.run`. Running `claude plugin test` inside the fixture reported **1 pass, 0 fail** with two stubbed tool calls and no real Shell side effects. The tool also warned about a gating hook without a catch handler; this is a deliberately small **test fixture**, not a recommended production security hook.

Command output (which contains the local source path) is in `evidence/runtime/K-0002-macbook-20261013.log`, with content-hash-bound JSON metadata. This proves the recorded CLI test-kit run, **not** production interactive hook execution or OS permission safety.
