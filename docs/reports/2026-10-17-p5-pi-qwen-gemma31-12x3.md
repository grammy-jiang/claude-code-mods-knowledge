# P5 local Pi Agent — Qwen3.6 vs Gemma 4 31B paired 12×3

Date: 2026-10-17 (Sydney). Exact frozen original 12-case cohort, three independent sessions per model per case. GPT-OSS 120B deferred.

## Models and scope

- Mac M5 Max, 128 GiB. Native Pi Agent 1.3.0 with isolation and read-only scoped tools. Normal automatic Skill discovery in all trials.
- Original reviewed Mods Skill SHA: `03053cc81e43ca215621db048eb435d675a2685205953019744a5df1bc13530e`; knowledge approved only for Claude Code CLI 2.1.296.
- Qwen3.6 35B-A3B was served by existing local Qwen oMLX endpoint; Gemma 4 31B by the independent oMLX MTP endpoint while Qwen was temporarily paused. Different weights/quantization make task-time comparison descriptive, not a strict identical-hardware latency A/B.
- Each model attempted 36 frozen tasks: 12 positives, 12 unrelated negatives, 12 boundary tasks. Research-only boundary model text was buffered privately and **never delivered as a verified answer**.
- Any model-generated runnable code remains blocked pending exact target CLI strict/mock and downstream-error identity testing.

## Safety, inference and restoration

- Resource guard retained. Gemma model was serially tested in six bounded Qwen maintenance windows; the Qwen launchd service was restored and its local models endpoint confirmed healthy after each window. Other four AI services remained running.
- Verified rollback windows: 6/6; per-round windows: 1=2, 2=2, 3=2.
- Original Pi global provider/model settings and installed Skill were not modified. No Claude model tokens, ChatGPT ordinary Chat-mode requests, or GPT-OSS 120B model calls.
- All original native JSONL, prompts, responses, local paths and private model-service logs stay in the protected Mac benchmark directory. This report stores only bounded case IDs, response metadata, SHA256 and fail-closed verdicts.

## Decision boundary

**Neither model is approved for unrestricted Mods Skill code delivery** unless it meets the complete source, runtime, version and output safety gates. Do not silently switch the existing Pi default based on this benchmark. The results guide a future model/guardrail choice rather than certifying full P5 host acceptance.
